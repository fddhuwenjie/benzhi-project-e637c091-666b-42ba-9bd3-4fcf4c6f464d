# 展柜微环境异常处置台

本项目面向博物馆藏品保管员、预防性保护专员和值班主管，提供展柜微环境异常的闭环处置工作台。系统支持传感器或人工异常登记、指纹去重、藏品级别与偏差幅度评估、方案审批、现场动作与证据记录、复测自动判定，以及连续达标后的安全关闭和档案检索。

服务由 Go 标准库实现并直接提供原生 HTML、CSS、JavaScript 页面及 JSON API，不需要 Node 构建链。业务数据保存在本地 JSON 快照中，提交时通过临时文件和原子替换保证完整性；审计轨迹同时追加到 JSONL 日志。写请求使用 `Idempotency-Key` 防止重复执行，并通过 `expected_revision` 进行乐观并发控制。

## 环境要求

- Go 1.23 或更高版本
- 可写的数据目录；默认使用项目根目录下的 `data/`

## 构建

```bash
go build ./cmd/showcaseguard
```

## 运行

默认仅监听高位回环地址 `127.0.0.1:19081`：

```bash
go run ./cmd/showcaseguard
```

可通过参数指定其他回环地址和数据目录：

```bash
go run ./cmd/showcaseguard -addr=127.0.0.1:19181 -data=./data
```

也可设置仅含端口号的 `PORT`，服务会绑定 `127.0.0.1:<PORT>`。显式 `-addr` 优先于 `PORT`。为避免意外暴露馆内处置数据，程序拒绝监听 `0.0.0.0` 和非回环地址。

启动后在浏览器访问 `http://127.0.0.1:19081/`。异常详情可通过 `/incidents/{id}` 直接访问，归档检索页面位于 `/archives`。

## 测试

运行全部单元与接口回归测试：

```bash
go test ./...
```

运行有界启动及完整业务冒烟检查：

```bash
go run ./cmd/showcaseguard -addr=127.0.0.1:19081 -self-check
```

`-self-check` 会实际启动 HTTP 服务，经 JSON 接口完成异常登记、方案提交与审批、现场动作、两次达标复测和档案检索，然后自行退出。未指定 `-data` 时使用临时目录并在结束后清理。

## 数据文件

- `data/snapshot.json`：展柜、事件、影响评估、方案、动作、复测、档案、幂等记录和审计视图的当前快照。
- `data/audit.jsonl`：只追加的审计事件日志。启动时会与快照核对，并补写提交过程中断导致的缺失日志。

不要在服务运行时手工修改数据文件。需要备份时，应同时复制 `snapshot.json` 和 `audit.jsonl`。
